# V2 frozen slice analysis

Post-freeze TEST/HOLDOUT slices cover family, environment, provider mode,
narrative state, candidate kind, and sequence/static status. The worst valid
multi-candidate family slice is `NOVELTY_PRESSURE` on TEST (pairwise about
0.7494); candidate-kind singleton slices are not ranking-valid and are excluded
from worst-slice comparisons. Sequence performance is below static performance
and is documented as future stateless-context work, without architecture change.
