# Real experience collection foundation

This phase supplies the observation bridge and an offline staging contract.
The current environment has no validated client gameplay session, so
`REAL_GAMEPLAY_EXPERIENCE_COLLECTED=NO` and external client validation remains
pending. Harness observations are explicitly synthetic infrastructure data,
not real gameplay.

No training is performed, no weights are changed, and no automatic reward or
quality assignment is made. Future curation must validate joins, completeness,
privacy, and session-level splits before any supervision design.
